# Implement and verify workflow

1. Read `AGENTS.md`, `specs/invoicepilot.md`, and the relevant implementation plan task.
2. For behavior changes, add a focused failing test before implementation.
3. Keep the change to one module responsibility and do not edit files owned by another lane.
4. Run the focused test; fix it; then run the full suite after integration.
5. Inspect `git diff` for secrets and unintended files.
6. Update the spec, `TODO.md`, and quality scorecard when behavior changes.
7. Commit a successful logical increment with a descriptive message.
